# Архитектура

## Схема

```
браузер — static/index.html (дашборд)
   │  fetch, JSON
   ▼
src/main.py ─────────── FastAPI: страница «/», обработчики ошибок, lifespan → startup()
   │
   ▼
src/api/endpoints.py ── эндпоинты; общее состояние state["model"], state["examples"]
   │            │                      │
   ▼            ▼                      ▼
ml/dataset.py   ml/model.py            ml/explain.py
UCI → data/     обучение, метрики,     прогноз по моментам,
students.csv    models/model.joblib    причины, показательные студенты
   │            │                      │
   └────────────┴── ml/features.py + ml/codes.json ──┘
                    признаки по моментам, названия, справочники кодов

src/schemas/student.py — Pydantic: StudentFeatures, PredictionResponse, TrainingConfig, ErrorResponse
```

## Модули

| Модуль | Отвечает за | Знает о |
|---|---|---|
| `src/main.py` | приложение FastAPI, страница `/`, единый формат ошибок, запуск модели при старте | эндпоинты, схемы |
| `src/api/endpoints.py` | HTTP: датасет, студенты, прогноз, обучение; держит текущую модель в `state` | всё в `src/ml`, схемы |
| `src/ml/dataset.py` | скачать zip с UCI, переименовать колонки, сохранить и загрузить `data/students.csv` | только pandas и httpx2 |
| `src/ml/features.py` | списки признаков по моментам (`STAGES`), категориальные (`CATEGORICAL`), исключённые (`EXCLUDED`), русские названия (`TITLES`), справочники (`CODES`) | `codes.json` |
| `src/ml/model.py` | пайплайн предобработки и модели, обучение трёх моментов, метрики, сохранение, история | `features`, `explain.typical_values` |
| `src/ml/explain.py` | прогноз на известные моменты, пакетный прогноз группы, причины риска, подбор показательных студентов | `features` |
| `src/schemas/student.py` | схемы запросов и ответов, проверка кодов и полноты семестров, пример для Swagger | `features` |
| `static/index.html` | страница: зачётка, «что если», шкала моментов, причины, панель модели | только HTTP API |

Модули `src/ml` ничего не знают о FastAPI — их можно звать из скрипта или ноутбука. Единственное место,
где перечислены признаки, — `src/ml/features.py`: из него берут списки обучение, прогноз, схемы
Pydantic и `/model/schema`.

## Запуск приложения

`lifespan` в `src/main.py` вызывает `startup()` из `src/api/endpoints.py`:

1. загрузить `models/model.joblib`;
2. если файла нет или он от другой версии scikit-learn — загрузить датасет (при отсутствии
   `data/students.csv` он скачивается с UCI), обучить логистическую регрессию, сохранить модель и
   запись в историю;
3. положить модель в `state["model"]`.

Если шаг не удался — например, нет интернета для первой загрузки датасета, — приложение всё равно
запускается: `/health` вернёт `model_loaded: false`, `/predict` — 400 «Модель не обучена».

## Путь запроса `/predict`

1. Pydantic проверяет тело как `StudentFeatures`: типы, диапазоны, коды по справочникам, семестры
   целиком, сдано ≤ записано.
2. `explain.predict()` находит моменты, для которых заполнены все признаки (`known_stages`), и для
   каждого зовёт `predict_proba` своего пайплайна.
3. `explain.reasons()` для последнего момента строит варианты «как у типичного студента», считает их
   одним вызовом `predict_proba` и оставляет три самых сильных.
4. Ответ — `PredictionResponse`. Прогноз с причинами занимает ~16 мс.

## Состояние и файлы

| Что | Где | В git |
|---|---|---|
| Датасет | `data/students.csv`; в памяти — после первого чтения (`dataset._cache`, его не изменять) | нет |
| Модель | `models/model.joblib`; в памяти — `state["model"]` | нет |
| История обучений | `models/training_history.json` | нет |
| Показательные студенты | `state["examples"]` — считаются при первом запросе, сбрасываются после обучения | — |
| Справочники кодов | `src/ml/codes.json` | да |

Модель — словарь: `model_type`, `hyperparameters`, `trained_at`, `stages` (три пайплайна scikit-learn),
`metrics`, `typical`, `test_ids`. Базы данных нет: всё помещается в память.

`POST /model/train` — синхронный обработчик (`def`, не `async def`): FastAPI выполняет его в отдельном
потоке, и обучение не останавливает остальные запросы.

## Ошибки

Обработчики в `src/main.py` приводят все ошибки к `ErrorResponse {code, message, details}`:

- `HTTPException` из Starlette — 400, 404, в том числе 404 на неизвестный адрес;
- `RequestValidationError` — 422, в `details` — все ошибки полей через «; »;
- любое другое исключение — 500, текст исключения в `details`, трассировка — в лог.

## Страница

Дашборд — один файл `static/index.html` без сборки и внешних библиотек: CSS и JavaScript внутри,
шрифты — системные (Segoe UI — текст, Bahnschrift — числа) с запасными вариантами. Работает без
интернета. Карточки: «Риск отчисления» и «Когда виден риск» сверху, ниже — «Студент», «Успеваемость»
и «Почему такой риск»; на узком экране — одна колонка.

Порядок загрузки: `/dataset/codes` и `/model/status` → `/students/examples` (примеры) → первый
студент (`/students/{id}`) → `/predict`. Ссылка `/?student=2192` сразу открывает нужного студента.
Правки «что если» живут только в браузере: страница меняет признаки и снова зовёт `/predict`.
Панель «Модель» зовёт `/model/train` и `/model/metrics`.

## Как расширять

- **Новый тип модели** — добавить запись в `MODEL_TYPES` (`src/ml/model.py`), значение в `Literal` у
  `TrainingConfig.model_type` (`src/schemas/student.py`) и название в `MODELS` (`static/index.html`).
- **Новый признак** — добавить в `ENROLLMENT` или `SEMESTER_FIELDS` и в `TITLES`
  (`src/ml/features.py`), поле в `StudentFeatures`, строку в `docs/data.md`. Категориальный — ещё в
  `CATEGORICAL`, справочник в `codes.json` и связь поля со справочником в `CODES`.
- **Новая причина риска** — ещё один вызов `add()` в `_alternatives()` (`src/ml/explain.py`).
- **Новый момент прогноза** (после 3-го семестра) — без новых данных невозможен: в датасете только два
  семестра.

## Тесты

`tests/test_main.py` поднимает приложение через `TestClient` (с `lifespan`). Модель и история
обучений подменяются временной папкой, `models/` не трогается. Проверяется:

- `/health`, `/dataset/info`, `/dataset/codes`;
- прогноз на три момента, на один и на два — по тому, какие семестры переданы;
- больше сданных предметов — ниже риск;
- ошибки 422: неизвестный код, неполный семестр, 2-й семестр без 1-го, сдано больше записанного, пустое тело;
- пакетный прогноз: студенты по убыванию риска, у каждого свой момент и тот же риск, что у `/predict`;
  422 на пустой список и на 501 студента;
- показательные студенты — из тестовой выборки, их признаки принимает `/predict`; 404 на неизвестного;
- обучение случайного леса и история; 422 на неизвестный `model_type`, 400 на неизвестный гиперпараметр.

Запуск — `python -m pytest -v`, несколько секунд.
