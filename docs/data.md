# Данные

## Источник

UCI Machine Learning Repository, датасет №697 «Predict Students' Dropout and Academic Success»
(Realinho, Vieira Martins, Machado, Baptista, 2021), https://doi.org/10.24432/C5MC89, лицензия
CC BY 4.0. Данные одного португальского вуза о студентах разных программ бакалавриата: агрономия,
дизайн, педагогика, сестринское дело, журналистика, менеджмент, социальная работа, технологии.
Авторы датасета — из Политехнического института Порталегре.

- 4 424 студента — по строке на студента;
- 36 признаков и исход `outcome`, пропусков и дублей нет;
- исход — на конец нормального срока обучения.

| Исход | Значение | Студентов | Доля |
|---|---|---|---|
| `graduate` | выпустился | 2 209 | 50 % |
| `dropout` | отчислен | 1 421 | 32 % |
| `enrolled` | ещё учится — не уложился в срок | 794 | 18 % |

## Как загружается

`src/ml/dataset.py` скачивает zip с сайта UCI, читает из него `data.csv` и сохраняет
`data/students.csv`. По дороге:

- исходный файл — с BOM в начале и разделителем `;`, читается с `encoding="utf-8-sig"`;
- у колонки `Daytime/evening attendance` в имени хвостовая табуляция — имена колонок очищаются от
  пробелов;
- колонки переименовываются в короткие имена проекта (таблицы ниже); в исходном файле опечатка —
  `Nacionality`, у нас `nationality`;
- исход `Dropout / Enrolled / Graduate` → `dropout / enrolled / graduate`;
- добавляется `student_id` — номер строки с 1, по нему работает `/students/{student_id}`;
- если в новой версии файла появятся незнакомые колонки, загрузка остановится с ошибкой — чтобы
  модель не обучилась молча на другом наборе признаков.

Папка `data/` в git не входит.

## Признаки семестров

Шесть полей на семестр: `sem1_*` — 1-й семестр, `sem2_*` — 2-й. Исходные имена —
`Curricular units 1st sem (…)` и `Curricular units 2nd sem (…)`.

| Поле | Исходное имя | Что значит | В данных |
|---|---|---|---|
| `semN_credited` | (credited) | Предметов перезачтено | 0–20 |
| `semN_enrolled` | (enrolled) | Записан на предметы | 0–26; медиана 6 |
| `semN_evaluations` | (evaluations) | Аттестаций — попыток сдать | 0–45 |
| `semN_approved` | (approved) | Сдано предметов | 0–26; всегда ≤ `semN_enrolled` |
| `semN_grade` | (grade) | Средний балл по сданным, 0–20 | 0 ровно тогда, когда ничего не сдано |
| `semN_no_evaluations` | (without evaluations) | Предметов без аттестации | 0–12 |

- У тех, кто записан хотя бы на один предмет, медианная доля сданных — 0,86 в 1-м семестре и 0,83
  во 2-м; медианный средний балл у сдавших — 12,6 и 12,7 из 20.
- У 180 студентов в каждом семестре `enrolled = 0`: все предметы перезачтены или студент не записался.
  Отчислены из них 43 % — почти как в среднем.
- В описании UCI у `Curricular units 2nd sem (without evaluations)` по ошибке написано «in the 1st
  semester» — по смыслу и по данным это 2-й семестр.

## Признаки, которые модель не использует

| Поле | Исходное имя | Что значит | Значения |
|---|---|---|---|
| `gender` | Gender | Пол | 1 — мужской, 0 — женский |
| `nationality` | Nacionality | Гражданство | код, 21 значение |
| `international` | International | Иностранный студент | 1 — да, 0 — нет; ровно то же, что `nationality ≠ 1` |

Они есть в датасете и в `/dataset/preview`, но в модель не идут, и `/predict` их не принимает:
прогноз риска не должен зависеть от пола и гражданства. Связь с исходом у пола сильная — юноши
отчислены в 45 % случаев, девушки в 25 %, — но качество без этих признаков почти не меняется: AUC
отчисления после 2-го семестра 0,918 с ними и 0,918 без них, при поступлении — 0,817 и 0,813
(5-кратная кросс-валидация, логистическая регрессия). Подробнее — [model.md](model.md#справедливость).
