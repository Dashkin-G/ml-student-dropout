# API

Все эндпоинты сервиса: запросы, ответы и ошибки. Базовый адрес при локальном запуске —
`http://127.0.0.1:8000`. Интерактивная схема — `/docs` (Swagger UI), машинная — `/openapi.json`.
Тексты ошибок и описания полей — на русском.

## Формат ошибок

Любая ошибка приходит одним форматом — `ErrorResponse`:

```json
{"code": 422, "message": "Неверные данные запроса", "details": "course: Value error, неизвестный код 1234, справочник — GET /dataset/codes"}
```

| Код | Когда |
|---|---|
| 400 | Модель не обучена; недопустимый гиперпараметр в `/model/train` |
| 404 | Нет студента с таким номером; неизвестный адрес |
| 422 | Неверные данные запроса: нет поля, неверный тип, неизвестный код, неполный семестр, неизвестный `model_type`, пустой или слишком длинный список в `/predict/batch` |
| 500 | Внутренняя ошибка сервера — текст исключения в `details` |

Для 422 в `details` перечислены все ошибки через «; » в виде `поле: сообщение`; ошибки, которые
касаются запроса целиком (например, неполный семестр), идут с полем `body`.

## Состояние

### GET /health

```json
{"status": "ok", "model_loaded": true, "dataset_available": true}
```

`model_loaded: false` — модель не обучилась при старте (например, не было интернета для скачивания
датасета). Обучить вручную — `POST /model/train`.

## Датасет

### GET /dataset/info

```json
{
  "rows": 4424,
  "columns": 37,
  "outcomes": {"dropout": 1421, "enrolled": 794, "graduate": 2209},
  "source": {
    "name": "Predict Students' Dropout and Academic Success",
    "url": "https://doi.org/10.24432/C5MC89",
    "authors": "Realinho V., Vieira Martins M., Machado J., Baptista L. (2021)",
    "license": "CC BY 4.0"
  }
}
```

`columns` — 36 признаков и исход, без служебного `student_id`.

### GET /dataset/preview?n=5

Первые `n` строк датасета (1–100) со всеми колонками, включая `student_id`, `outcome` и признаки,
которые модель не использует (`gender`, `nationality`, `international`).

### GET /dataset/codes

Справочники кодов для категориальных признаков: `{поле: {"title": название, "codes": {код: значение}}}`.
Поля: `marital_status`, `application_mode`, `course`, `previous_qualification`, `nationality`,
`mother_qualification`, `father_qualification`, `mother_occupation`, `father_occupation`. У матери и
отца справочники общие. Пример — программы обучения:

```json
{"course": {"title": "Программа обучения", "codes": {"33": "Технологии производства биотоплива", "171": "Анимация и мультимедийный дизайн", "9500": "Сестринское дело", "...": "..."}}}
```

Полные таблицы — в [data.md](data.md).

## Студенты

### GET /students/examples

Шесть показательных студентов из тестовой выборки — кнопки-примеры на дашборде. Подбираются заново
после каждого обучения по прогнозам текущей модели:

| Пример | Как выбирается |
|---|---|
| Высокий риск | Отчисленный с самым высоким риском после 2-го семестра — среди тех, кто во 2-м семестре что-то сдал и чей риск ниже 95 % (иначе «что если» нечего показать) |
| Риск вырос за год | Отчисленный с самым большим ростом риска от поступления до 2-го семестра |
| Риск снизился за год | Выпускник с самым большим падением риска |
| Ещё учится | Студент с исходом «ещё учится» и самой высокой вероятностью этого исхода |
| Уверенный выпускник | Выпускник с самым низким риском |
| Модель ошиблась | Выпускник с самым высоким риском — ложная тревога |

```json
[
  {"student_id": 3293, "title": "Высокий риск", "course": 9238, "outcome": "dropout", "risk_start": 0.2361, "risk_end": 0.9434},
  {"student_id": 2192, "title": "Риск вырос за год", "course": 9500, "outcome": "dropout", "risk_start": 0.0768, "risk_end": 0.9898}
]
```

`risk_start` — риск при поступлении, `risk_end` — после 2-го семестра.

### GET /students/random

Случайный студент из тестовой выборки — ответ такой же, как у `/students/{student_id}`.

### GET /students/{student_id}

Номер — от 1 до 4 424 (строка датасета). Ответ:

```json
{
  "student_id": 3293,
  "split": "test",
  "outcome": "dropout",
  "features": {"marital_status": 1, "application_mode": 1, "course": 9238, "age": 27, "...": "...",
               "sem2_enrolled": 6, "sem2_approved": 1, "sem2_grade": 11.0}
}
```

- `split`: `test` — студент из тестовой выборки, модель его не видела; `train` — был в обучении.
- `outcome` — настоящий исход из датасета.
- `features` — ровно те поля, что принимает `/predict`: ответ можно сразу отправить на прогноз.

Нет такого студента — 404: `"Студента № 99999 нет: номера от 1 до 4424"`.

## Прогноз

### POST /predict

Тело — признаки студента (`StudentFeatures`, 33 поля). Описание каждого поля — в [data.md](data.md)
и в Swagger. Поля семестров необязательны:

| Что передано | Моменты в ответе |
|---|---|
| Только признаки поступления | `enrollment` |
| + все шесть полей `sem1_*` | `enrollment`, `semester_1` |
| + все шесть полей `sem2_*` | все три |

Проверки, кроме типов и диапазонов полей:
- код категориального признака должен быть в справочнике (`GET /dataset/codes`);
- семестр передаётся целиком — все шесть полей `semN_*` или ни одного;
- 2-й семестр без 1-го не принимается;
- сдано предметов не больше, чем записано (`semN_approved ≤ semN_enrolled`).

Пример ответа — студент № 2192 (этот пример стоит в Swagger по умолчанию):

```json
{
  "stages": [
    {"stage": "enrollment", "title": "При поступлении",
     "probabilities": {"dropout": 0.0768, "enrolled": 0.1074, "graduate": 0.8158}, "outcome": "graduate"},
    {"stage": "semester_1", "title": "После 1-го семестра",
     "probabilities": {"dropout": 0.9712, "enrolled": 0.028, "graduate": 0.0009}, "outcome": "dropout"},
    {"stage": "semester_2", "title": "После 2-го семестра",
     "probabilities": {"dropout": 0.9898, "enrolled": 0.0102, "graduate": 0.0}, "outcome": "dropout"}
  ],
  "risk": 0.9898,
  "reasons": [
    {"feature": "sem2_approved", "text": "сдано 0 из 8 во 2-м семестре", "typical": "обычно 7 из 8",
     "raises_risk": true, "risk_if_typical": 0.5283, "shift": 4.462},
    {"feature": "sem1_approved", "text": "сдано 0 из 7 в 1-м семестре", "typical": "обычно 6 из 7",
     "raises_risk": true, "risk_if_typical": 0.9835, "shift": 0.487}
  ]
}
```

- `stages` — прогноз на каждый момент, для которого хватает признаков; `outcome` — самый вероятный
  исход.
- `risk` — вероятность отчисления на последний известный момент.
- `reasons` — до трёх причин для последнего момента. `risk_if_typical` — каким был бы риск, будь
  этот признак как у типичного студента; `shift` — сдвиг шансов отчисления в логитах, по нему
  причины упорядочены. Как они считаются — [model.md](model.md#причины-риска).

Студент № 2192 при поступлении выглядел будущим выпускником (риск 8 %), но в 1-м семестре не сдал
ни одного из 7 предметов — и риск вырос до 97 %.

### POST /predict/batch

Риск сразу для группы — например, для всего курса перед сессией. Тело — список `students` от 1 до
500 студентов; у каждого те же поля и проверки, что у `POST /predict`, семестры у студентов могут
быть разными:

```json
{"students": [{"marital_status": 1, "application_mode": 1, "...": "..."}, {"...": "..."}]}
```

Ответ — студенты по убыванию риска, без причин (причины одного студента — `POST /predict`). Пример —
студент № 2192 трижды: только с признаками поступления, со всеми семестрами и без 2-го семестра:

```json
{
  "count": 3,
  "levels": {"high": 2, "medium": 0, "low": 1},
  "high_share": 0.6667,
  "students": [
    {"index": 1, "stage": "semester_2", "risk": 0.9898, "level": "high", "outcome": "dropout"},
    {"index": 2, "stage": "semester_1", "risk": 0.9712, "level": "high", "outcome": "dropout"},
    {"index": 0, "stage": "enrollment", "risk": 0.0768, "level": "low", "outcome": "graduate"}
  ]
}
```

- `index` — номер студента в запросе, с нуля: по нему ответ сопоставляется с запросом.
- `stage` — последний момент, для которого хватает признаков; `risk` — риск отчисления на этот
  момент, такой же, как у `POST /predict`.
- `level` — уровень риска, как на дашборде: `high` — от 50 %, `medium` — 25–50 %, `low` — до 25 %;
  `levels` — сколько студентов на каждом уровне, `high_share` — доля высокого риска.
- Пустой список или больше 500 студентов — 422. 500 студентов считаются за ~30 мс: по одному вызову
  модели на момент.

## Модель

### POST /model/train

```json
{"model_type": "random_forest", "hyperparameters": {"n_estimators": 200}}
```

- `model_type`: `logreg` (по умолчанию), `random_forest`, `boosting`. Другое значение — 422.
- `hyperparameters` — параметры конструктора модели scikit-learn; дополняют параметры по умолчанию
  (см. [model.md](model.md#модели)). Неизвестный параметр — 400:
  `"Не удалось обучить logreg: LogisticRegression.__init__() got an unexpected keyword argument 'depth'"`.

Обучаются три модели — по одной на момент. Новая модель сразу заменяет текущую, сохраняется в
`models/model.joblib` и дописывается в историю. Ответ — тип, время и метрики по моментам (формат
метрик — как в `/model/status`). Время обучения всех трёх моментов: логистическая регрессия ~0,4 с,
случайный лес ~1,7 с, бустинг ~3 с.

### GET /model/status

```json
{
  "trained": true,
  "model_type": "logreg",
  "hyperparameters": {},
  "trained_at": "2026-10-12T23:15:54",
  "metrics": {
    "semester_2": {
      "accuracy": 0.7209, "f1_macro": 0.6847, "auc_dropout": 0.9107,
      "recall": {"dropout": 0.6796, "enrolled": 0.6352, "graduate": 0.7783},
      "confusion": [[193, 66, 25], [28, 101, 30], [16, 82, 344]],
      "test_size": 885
    }
  },
  "typical": {"age": 20.0, "admission_grade": 126.0, "sem1_pass_rate": 0.857, "sem1_grade": 12.64,
              "sem2_pass_rate": 0.833, "sem2_grade": 12.67}
}
```

- `metrics` — по каждому моменту (`enrollment`, `semester_1`, `semester_2`) на тестовой выборке.
  `confusion` — матрица ошибок: строки — настоящий исход, столбцы — прогноз, порядок `dropout`,
  `enrolled`, `graduate`.
- `typical` — типичный студент обучающей выборки, с ним сравниваются причины: медианы возраста и
  вступительного балла, медианная доля сданных предметов и медианный средний балл у тех, кто сдал.

Модель не обучена — `{"trained": false}`.

### GET /model/schema

Какие признаки использует каждый момент (`stages`), русские названия признаков (`features`),
признаки датасета, которые модель сознательно не использует (`excluded`: `gender`, `nationality`,
`international`), и названия исходов (`outcomes`).

### GET /model/metrics?n=5

Последние `n` записей истории обучений (`models/training_history.json`): время, тип модели,
гиперпараметры и `accuracy`, `f1_macro`, `auc_dropout` по каждому моменту.
