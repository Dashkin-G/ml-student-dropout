# Риск отчисления студентов

Сервис на FastAPI и scikit-learn предсказывает исход учёбы студента — **отчислят**, **ещё учится**
или **выпустится** — в три момента: при поступлении, после 1-го и после 2-го семестра. Дашборд
показывает риск отчисления, как он менялся по ходу учёбы, его причины и «что если».

Данные — открытый датасет UCI «Predict Students' Dropout and Academic Success»: 4 424 студента
португальского вуза, 36 признаков, лицензия CC BY 4.0.

## Быстрый старт

```bash
python -m venv .venv
.venv\Scripts\activate          # Linux / macOS: source .venv/bin/activate
pip install -r requirements.txt
uvicorn src.main:app --reload
```

- http://127.0.0.1:8000 — дашборд;
- http://127.0.0.1:8000/docs — Swagger UI.

При первом запуске сервис сам скачивает датасет в `data/students.csv` (~0,5 МБ, нужен интернет) и
обучает логистическую регрессию (около секунды). Модель сохраняется в `models/model.joblib`, при
следующих запусках загружается с диска. Скачать датасет заранее: `python -m src.ml.dataset`.

## Дашборд

- **Примеры над карточками** — показательные студенты из тестовой выборки, модель их не видела:
  «Высокий риск», «Риск вырос за год», «Риск снизился за год», «Ещё учится», «Уверенный
  выпускник», «Модель ошиблась». Справа — поиск по номеру студента и «Случайный».
- **«Риск отчисления»** — крупное число и уровень: низкий — до 25 %, средний — 25–50 %, высокий — от
  50 %. Полоса под ним — вероятности всех трёх исходов.
- **«Когда виден риск»** — риск в три момента и AUC модели каждого момента. Щелчок по моменту
  показывает прогноз так, будто сейчас этот момент: более поздние семестры «ещё не было».
- **«Успеваемость»** — «что если»: сданные предметы и средний балл меняются кнопками −/+. Полоса
  «Доля сданных» показывает, сколько сдано от записанного, черта на ней — сколько сдаёт типичный
  студент.
- **«Студент»** — программа, поступление, оплата, долг и стипендия (щелчок по «да / нет» меняет
  значение), настоящий исход из датасета и совпал ли с ним прогноз.
- **«Почему такой риск»** — до трёх признаков, сильнее всего сдвигающих риск, и каким был бы риск,
  будь признак как у типичного студента.
- Правки подсвечиваются, прогноз пересчитывается сразу; «вернуть как было» в карточке риска
  отменяет все правки.
- **«Модель» в шапке** — качество по моментам, выбор модели, переобучение и история обучений.

## API

Эндпоинты сервиса — 12 штук: состояние, датасет, студенты, прогноз и модель.

| Метод | URL | Что делает |
|---|---|---|
| GET | `/health` | Состояние: загружена ли модель, есть ли датасет на диске |
| GET | `/dataset/info` | Размер датасета, распределение исходов, источник |
| GET | `/dataset/preview?n=5` | Первые N строк датасета |
| GET | `/dataset/codes` | Справочники кодов: программы, способы поступления, образование и профессии родителей |
| GET | `/students/examples` | Шесть показательных студентов из тестовой выборки |
| GET | `/students/random` | Случайный студент из тестовой выборки |
| GET | `/students/{student_id}` | Признаки студента и его настоящий исход |
| POST | `/predict` | Прогноз по моментам и причины риска |
| POST | `/model/train` | Обучение: `logreg`, `random_forest` или `boosting` |
| GET | `/model/status` | Тип модели, метрики по моментам, «типичный студент» |
| GET | `/model/schema` | Признаки каждого момента и исключённые признаки |
| GET | `/model/metrics?n=5` | История обучений |

Запросы, ответы и ошибки — [docs/api.md](docs/api.md).

## Качество

Логистическая регрессия на тестовой выборке — 885 студентов, 20 % датасета:

| Момент прогноза | AUC отчисления | Точность | F1 (macro) |
|---|---|---|---|
| При поступлении | 0,81 | 56 % | 0,53 |
| После 1-го семестра | 0,90 | 69 % | 0,65 |
| После 2-го семестра | 0,91 | 72 % | 0,68 |

Чем позже момент, тем точнее прогноз: результаты сессий — самые сильные признаки. Сравнение трёх
моделей, устройство причин и ограничения — [docs/model.md](docs/model.md).

## Структура проекта

```

├── src/
│   ├── main.py              — приложение FastAPI, обработчики ошибок, страница
```

Как модули связаны между собой — [docs/architecture.md](docs/architecture.md). Все признаки и коды —

## Тесты

```bash
python -m pytest -v
```

Тесты поднимают приложение через `TestClient`, обучают модель во временной папке и не трогают
`models/`. Датасет при отсутствии скачивается.

## Docker

```bash
docker build -t ml-student-dropout .
docker run -p 8000:8000 ml-student-dropout
```

Внутри контейнера датасет скачивается при первом запуске — контейнеру нужен интернет.
